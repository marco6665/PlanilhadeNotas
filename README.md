# Organizador de Notas — múltiplas disciplinas e turmas

Abra `index.html` no navegador ou use Live Server no VS Code.

O topo possui:
- Disciplina
- Turma
- Professor(a)
- Bimestre

Você pode trocar esses dados para cada turma/disciplina antes de lançar as notas.

Pesos:
- Livro do Estudante: 10%
- Caderno: 20%
- Lista de Exercícios: 10%
- Prova Paulista: 50%
- 10% ainda pendentes

A média exibida é a média ponderada dos 90% definidos. Os 10% pendentes não são redistribuídos.

Observação: esta versão não salva os dados depois de fechar/recarregar a página. Para uma próxima versão, pode-se adicionar banco de dados ou exportação para Excel.
